## The line

> Our office printer jams only on the document marked URGENT, which is how I learned machines can smell fear.

107 characters, one line, about office life.

## How it works

`main.py` (Python 3.13, standard library only) writes the line above
to `/output/entry.txt` — no network, no randomness, no model calls,
so both grading runs write byte-identical output.

## Run it locally

```sh
python3 main.py
cat /output/entry.txt
```

## Why this line

It turns on a real office detail everyone recognises — the printer
that only jams on the one document you actually need — escalates it
(the jam is not random, it only strikes the urgent page), and lands
the laugh in the last few words: the machine is not broken, it can
smell fear. One reading, no setup to explain, fresh wording.
